## 项目定位

**不是**：算命网站、玄学工具、娱乐项目

**而是**：易学推演系统、变化分析系统、AI决策辅助系统、东方哲学知识引擎、复杂系统模拟平台

核心目标：将阴阳、八卦、六十四卦、爻变、五行、时空关系全部**结构化**，形成**变化推演引擎**。

## 核心设计原则

1. **AI不计算，只解释** - 规则引擎负责确定性计算，AI负责自然语言解释
2. **变化结构化** - 核心目标是将"变化"本身结构化，而非预测结果
3. **模块化单体** - 初期高效率开发，后期可拆分微服务
4. **插件化扩展** - 支持梅花易数、奇门遁甲、紫微斗数等体系扩展
5. **事件驱动** - 层间解耦，支持异步处理
6. **不可变数据** - 所有核心数据结构使用 frozen dataclass
