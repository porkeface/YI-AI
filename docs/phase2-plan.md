# Phase 2 实施计划

> 目标: 建立知识图谱、长期记忆、完整RAG系统，提升AI解释质量

---

## 实施策略

Phase 2 涉及外部基础设施（Neo4j, Qdrant, Redis），采用分层推进：

### 第一批: 纯代码实现（无外部依赖）
1. **多模型路由** (M2.3) — 4-Tier模型路由 + Fallback
2. **梅花易数** (M2.5) — 新增起卦方式
3. **推演引擎v1** (M2.6) — 状态转移 + 3步推演

### 第二批: 需要基础设施
4. **知识图谱** (M2.1) — Neo4j 图谱设计 + 初始化脚本
5. **三路RAG** (M2.2) — 向量 + 图谱 + 规则检索融合
6. **长期记忆** (M2.4) — 4层记忆架构

### 第三批: 集成与发布
7. **v1.0发布** (M2.7) — 集成测试、部署、前端增强
